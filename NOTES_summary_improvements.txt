most recent attempted improvement is summarized as follows:

Recommendation: analytical Monte Carlo
The key insight is that gamma richness is deterministic given the scaling factor and the plant distribution. Inside simulateScaledSpeciesRichness, the species count is just:

gamma = sum(ceiling(plant_distribution_binned$n * scaling_factor))




The spatial simulation decides WHERE species go, but not HOW MANY there are. So you don't need to run the simulation at all for the error bounds — just vary the scaling factor and sum.

The approach
Get joint parameter uncertainty from both NLS fits — vcov(lognorm_fit) for the plant fit and vcov(lognorm_fit_animal) for the animal fit. These 3×3 covariance matrices describe how (amplitude, meanlog, sdlog) co-vary.

Draw 10,000 parameter combinations from multivariate normals for each. For each draw:

Compute plant_fit_max_draw = a_plant * dlnorm(mode, meanlog, sdlog) where mode = exp(meanlog - sdlog^2)
Compute animal_max_draw similarly from the animal parameter draw
scaling_factor_draw = animal_max_draw / plant_fit_max_draw
gamma_draw = sum(ceiling(plant_distribution_binned$n * scaling_factor_draw))
Take quantiles of the 10,000 gamma richness values → your CI.

Why this is better
Current	Proposed
Compute	200 bootstraps + 3 full spatial sims	10K draws of pure arithmetic
Runtime	Hours	Seconds
Uncertainty sources	Plant curve shape only	Plant NLS params + animal NLS params jointly
Scaling factor	Fixed	Varies with each draw
Bound width	Tight	Wider, more realistic
You'd still run one spatial simulation for the best estimate (needed for the downstream spatial output). The bounds calculation becomes essentially free.
