# Plan: Publication figures for AmAni cross-organism results

## Context
- `AmAni.summarize.R` currently only sources utils; `utils/summarize_all.R` is one 1,180-line function that reads data, writes CSVs and draws ~20 quick-look PDFs inline.
- Data needed already gets parsed in `summarize_all()`:
  - `extinction_summary` (summary_all_models.csv: model x scenario, median/IQR/min/max spp lost, pop lost)
  - `gamma_summary` / `organism_summary` (dataset_summary_*.txt, gamma_richnessfromSPRICH*.txt, sampling_extension_report_*.txt)
  - `iucn_all` (iucn_threat_classification_data.rds, `$counts`; not every organism has it, e.g. antbirds)
  - `scrape_dataset_summary_stats()` gives per-cell five-number summaries before/after filtering.
- Problem: parsing and plotting are entangled, so new figures can't reuse the data without re-running everything.

## Approach
1. **Separate data from plotting.** Write loader functions that return tidy tibbles (lifted from the existing parsing code in summarize_all.R, not rewritten):
   - `collect_extinction_summary(organisms)`
   - `collect_organism_summary(organisms)` (filter + gamma + sampling extension fields; replaces both `gamma_summary` and `organism_summary`)
   - `collect_dataset_distributions(organisms)` (wraps `scrape_dataset_summary_stats()`)
   - `collect_iucn(organisms, model, scenario)` (keep all models/scenarios available)
   - `collect_pub_data(include, group)` -> one named list used by all three figures.
2. **Shared publication style** (`theme_amani_pub()`, `amani_palettes`):
   - one fixed colour per organism / taxonomic group (insects vs vertebrates) used across all figures
   - IUCN official colours (already defined), consistent organism ordering (by group, then gamma richness)
   - sizes for a journal page (single column 89 mm / double 183 mm), base font ~7-8 pt, `ggsave()` to PDF (cairo) + PNG 600 dpi
   - patchwork layouts with panel tags (a, b, c...).
3. **Three multi-panel figures**, each a `fig_*()` function taking the data list and returning a patchwork object, plus a `save_pub_fig()` helper.

### Figure 1 — Sampling and filtering
Rows = organisms (shared y-axis, grouped insects / vertebrates), aligned panels:
- a. Raw data scale: records, grid cells, species before (light) and after (dark) filtering, dumbbell/lollipop on log x-axes.
- b. Retention: % records / cells / species retained (dot plot, 0-100%).
- c. Per-cell completeness / richness distributions before vs after (compact boxplots from five-number summaries).
- d. Optional small inset map: spatial footprint of retained cells (from existing `plot_spatial_extent_overlap()` data) or a single count of well-sampled vs super-diverse cells as a stacked bar.
Message: how much data went in, how much survived filtering, and how well-sampled the analysed cells are.

### Figure 2 — Gamma richness
- a. Main panel: per organism, a horizontal "ladder" on log scale: observed (pre-filter) -> analysed (post-filter) -> surrogate gamma (CI) -> full-model gamma (CI); point-range per step, organisms as rows. Replaces the current slope graph (labels overlapping).
- b. Expansion ratio (gamma / observed) as dot + CI, with 1x reference line.
- c. Composition bar: observed vs predicted-unsampled share of gamma (the stacked plot, made proportional & horizontal, total annotated).
- d. Optional: richness shortfall vs sampling completeness scatter (one point per organism) to show *why* expansion varies.

### Figure 3 — Extinction and IUCN
- a. Projected species lost (median + IQR + min-max range) per organism under the headline model/scenario, expressed both as count and as % of gamma richness (second axis or paired panel).
- b. Sensitivity: small-multiple dot plot across frequency scenarios (Under/Boundary/Calibrated/Over) and spatial models (Neutral/Clustered/endemism variants) — one row per organism, showing the spread.
- c. IUCN categories: horizontal 100% stacked bar per organism (NT/LC, VU, EN, CR/EX), absolute threatened count annotated at right.
- d. Optional: population losses (median_pop_lost) as a companion to species loss.

4. **Prototype in `AmAni.summarize.R`**: after the existing `source()` block, add sections: data collection, theme/palettes, Fig 1, Fig 2, Fig 3, save. Iterate interactively on real output (start with `group = "vertebrates"` and `"insects"`).
5. **Migrate** once stable: loaders + figures into `utils/` (e.g. `utils/pub_data.R`, `utils/pub_theme.R`, `utils/pub_fig_sampling.R`, `utils/pub_fig_gamma.R`, `utils/pub_fig_extinction.R`), and have `summarize_all()` call `collect_pub_data()` instead of its inline parsing. Leave old quick-look plots in place until replaced.
