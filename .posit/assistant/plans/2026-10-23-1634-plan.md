# Add top-site labels to the 3D retained-cells plot

## Feasibility
Yes. `fig_retained_cells_3d()` (utils/pub_3_fig_sampling.R:110) uses rayshader/rgl, and `rayshader::render_label()` places text (with a leader line) at a matrix position and height. The label selection already exists: `select_label_cells()` returns the top cell per country + next 8 overall, with rank, X/Y in the map CRS, and `grid_id`. Names come from `RETAINED_CELL_SITES`.

Limits compared with the 2D map:
- rgl text has no `ggrepel`-style collision avoidance, so labels may overlap in dense areas (Yasuni / Napo / Madre de Dios clusters).
- Font is rgl's, not Arial.
- Long names (e.g. the Finca Bella Vista entry) will be unwieldy in 3D.

Proposed approach: label the 3D plot with the rank number only (e.g. "1", "2"), matching the numbering on the 2D labelled map, so the 2D map or a key serves as the legend. Optional flag for full names.

## Plan
1. Refactor lightly: in `fig_retained_cells_3d()` add args `labels = FALSE`, `n_next = 8`, `label_names = FALSE`, `label_size`.
2. When `labels = TRUE`, call `select_label_cells(cell_stats, n_next)` (reuse; no duplicated selection logic). Build label text as the rank, or "rank. name" (via the same join/coalesce/`.wrap_two_lines` as `label_retained_cells()`; factor this into a small shared helper `.label_table()` used by both).
3. Convert map coordinates to height-matrix indices: `x_idx = (X - xmin) / (xmax - xmin) * nrow(height_mat)`, `y_idx` from the north edge (verify orientation against `height_mat`; rayshader matrices have rows = x and columns running north to south). Look up z as `height_mat` at that index (n_retained * height scale).
4. After `plot_3d()` and `render_camera()` but before `render_snapshot()`, call `rayshader::render_label(height_mat, text, x, y, z, zscale = 1 / height_per_organism, textsize, linewidth, relativez = FALSE, freetype = FALSE, clear_previous = TRUE)` once per label (loop; it takes one label per call).
5. Choose label altitude above column top (so lines clear taller neighbours) and test whether `freetype = FALSE` is required (it depends on the rgl build).
6. Update callers: pass `labels = TRUE` in AmAni.summarize.R (line 80) and `pub_6_make_figures.R` (line 52). Keep default `FALSE` so existing output is unchanged.
7. Test by rendering to a PNG in the scratch dir, inspect it for overlap and positioning (check that rank 1 sits on the expected cell), and adjust altitude/size, or use a hand-offset for crowded labels if needed.
8. Optional: also write a small key (rank -> site name) alongside the `_legend.png` if numbers-only is used.
