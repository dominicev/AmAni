NOT YET IMPLEMENTED
-------------------

4. [WON'T FIX] EPSG:3857 is not equal-area.
   The code comment says "Reproject to an equal-area CRS (e.g., UTM)" but
   uses Web Mercator (3857), which is conformal. Grid cells at the equator
   vs. at ~15 S represent ~6% different real-world areas.

   Justification for leaving as-is:
   - The pipeline is internally consistent: all stages that use the species
     grid (0, 1, 2, 4) share the same projection, so no stage introduces a
     mismatch.
   - Richness, endemism, range size, and extinction counts are all based on
     cell counts (presence/absence), not cell areas. A species in 3 cells
     has range_size = 3 regardless of whether those cells are exactly 500
     km² each.
   - The adjacency list operates on grid topology (which cells neighbor
     which), not metric distances. Since the grid was created in 3857, the
     neighbors are the correct topological neighbors.
   - Stage 3 (patch extraction) independently uses EPSG:5880 (South America
     Albers Equal Area) for patch area calculations, so deforestation patch
     sizes are not affected by the species grid CRS.
   - The ~6% area distortion across the Amazon's latitude range (5 N to
     18 S) is small relative to other sources of uncertainty in the pipeline
     (simulated ranges, sampling bias, taxonomic completeness).
   - Changing the CRS would require regenerating all Stage 0-1 outputs, the
     adjacency list, and all organism model runs, with high risk of
     introducing mismatches between old and new outputs for minimal gain.
