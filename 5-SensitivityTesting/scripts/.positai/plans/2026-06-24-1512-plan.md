# Fix: Multimodal range distributions from `biased_species_sample`

## Problem

`biased_species_sample` uses `ntile()` to assign species to discrete quantile bins, then applies a uniform weight to all species within each bin. This creates hard discontinuities in sampling probability at bin boundaries, producing multimodal `n_cells` distributions in the output — even when the input distribution is unimodal.

## Proposed Fix: Continuous weight interpolation

Replace the discrete bin → weight mapping with a **smooth, continuous weighting function** that interpolates between the user-supplied quantile weights based on each species' percentile rank in `n_cells`.

### How it works

1. Compute each species' percentile rank in `n_cells` (0 to 1).
2. Treat the user-supplied `weights` vector as control points at the midpoints of each quantile class (e.g., for 5 quantiles: ranks 0.1, 0.3, 0.5, 0.7, 0.9).
3. Use `approx()` (linear interpolation) to assign each species a weight that transitions smoothly between the quantile-class weights.
4. Normalize to probabilities and sample as before.

### Interface changes

- **No change to the function signature.** `n_quantiles` and `weights` are still supplied; they just define interpolation control points rather than hard bins.
- The `quantile_shift` diagnostic will still be returned (species are still *classified* into quantile bins for reporting purposes), but the actual sampling probabilities are continuous.
- Add a `smooth` parameter (default `TRUE`) to allow toggling back to the original discrete behavior if needed for comparison.

### Changes to `helpers.R`

Modify `biased_species_sample` (~lines 76–130):

- After step 1, compute `pct_rank = rank(n_cells, ties.method = "average") / n()` for each species.
- Define control points at quantile midpoints: `midpoints = (seq_len(n_quantiles) - 0.5) / n_quantiles`.
- Interpolate: `weight = approx(midpoints, weights, xout = pct_rank, rule = 2)$y`.
- Steps 5–7 proceed unchanged (normalize, sample, diagnostics).

### What stays the same

- `make_weights()` — no changes needed.
- `species_richness_sample` — could receive the same fix later, but is out of scope here.
- `rebuild_community` — unaffected.
- The diagnostic `quantile_shift` table still uses discrete bins for interpretability.
