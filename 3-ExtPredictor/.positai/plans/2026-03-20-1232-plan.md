# Plan: Reorganize 4-ExtModeller

## Current state

```
4-ExtModeller/
├── SimulateExtinction.R          (neutral/spatially random simulation)
├── functions.R                   (shared utility functions)
├── extinction_results_Freq*.RData (3 cached result files)
├── .RData, .RDataTmp, .RDataTmp1, .Rhistory (session files)
```

Everything is flat in the root. No scripts/ folder, no archive/.

## Proposed structure

```
4-ExtModeller/
├── scripts/
│   ├── 01_simulate_neutral.R        (renamed from SimulateExtinction.R)
│   ├── 02_simulate_clustered.R      (NEW — spatially clustered deforestation)
│   └── utils/
│       └── simulation_functions.R   (renamed from functions.R)
├── output/
│   └── (RData files moved here)
├── archive/
│   └── (.RData session files, .RDataTmp*, .Rhistory)
└── AGENTS.md
```

## Steps

1. **Create directories**: `scripts/`, `scripts/utils/`, `output/`, `archive/`
2. **Move files**:
   - `SimulateExtinction.R` → `scripts/01_simulate_neutral.R`
   - `functions.R` → `scripts/utils/simulation_functions.R`
   - `extinction_results_Freq*.RData` → `output/`
   - `.RData`, `.RDataTmp*`, `.Rhistory` → `archive/`
3. **Update paths** in `01_simulate_neutral.R`:
   - `source("./functions.R")` → `source("scripts/utils/simulation_functions.R")`
   - `list.files(pattern = ...)` for RData caching → prepend `"output/"`
   - `save(..., file = ...)` → prepend `"output/"`
   - `setwd` logic to use project root (not scripts/ folder)
4. **Create `scripts/02_simulate_clustered.R`**:
   - Copy from `01_simulate_neutral.R` as starting point
   - Modify the deforestation placement to be spatially clustered rather than uniform random
   - The key difference: instead of `sample(available_grids, ...)` uniformly, weight grid selection by proximity to deforestation hotspots or use a spatial kernel
   - Mark sections that need further development with TODO comments
   - Use distinct output filenames (`*_clustered_*.RData`)
5. **Update `simulation_functions.R`**: add a `method` parameter to `run_large_patch_deforestation` and `run_small_patch_thinning` (or create separate clustered versions) so both scripts can share the same function file
6. **Create `AGENTS.md`** for the 4-ExtModeller project

## Notes

- Both scripts should `setwd()` to the project root (`4-ExtModeller/`) so paths are relative from there
- The clustered version is a scaffold — the spatial weighting logic needs further development, but the file structure and data flow should be complete
- `extModelDir` path (pointing to `3-ExtPredictor/output`) doesn't change since it's already computed relative to `dirname(getwd())`
